# Beepstock branding

Logo files for **Beepstock** . All SVGs are self-contained vectors (the lettering is converted to
outlines, so no font is needed to display them).

| File | Use |
|---|---|
| `logo-icon.svg` / `logo-icon-512.png` / `logo-icon-192.png` | App icon with rounded corners (web manifest, avatars) |
| `logo-icon-bleed.svg` / `apple-touch-icon.png` | Full-bleed square, for platforms that apply their own corner mask |
| `favicon.svg` / `favicon-64.png` / `favicon-32.png` | Simplified mark that stays readable at 16-32 px |
| `logo-mark.svg` | Mark without the tile (brand-blue bars, coral scanner beam), for tinted or light backgrounds |
| `logo-wordmark.svg` / `.png` | Icon + name for light backgrounds |
| `logo-wordmark-dark.svg` / `.png` | Icon + name for dark backgrounds |
| `social-preview.svg` / `.png` | 1280 x 640 image for the repository's social preview |

## Colours

| Name | Hex | Use |
|---|---|---|
| Blue | `#2f7dff` | Gradient start, mark |
| Violet | `#6b4dff` | Gradient end |
| Coral (scanner beam) | `#ff5d7a` (`#ff7a93` on dark) | "beep" in the wordmark, accents |
| Navy | `#0f1b3d` | "stock" in the wordmark on light backgrounds |

## Usage

* Keep clear space around the logo of at least the width of the thinnest bar group (about 1/8 of the icon).
* Do not recolour the gradient, stretch the logo or change the order of the bars.
* Write the name as **Beepstock** in running text.
